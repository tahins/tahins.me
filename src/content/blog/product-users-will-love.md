when was the last time you used a product? okay, this question doesn’t make any sense at all. you are probably reading this using a desktop, mobile, tab or even watch(!!!). so you are using a product right now. we all use so many products everyday that it almost became like air. it’s always there, but we don’t realize. there so many categories of product we use everyday. some are for offline use, others are for online. some work digitally, others don’t. 

we use so many products everyday that often we think we know what a product is. as a product manager, when we think about a product or design one we should take a step back and ask ourselves a very basic question. What is a product?

What is a product?

a product is something that serves a purpose for the users or does something for them. the toothbrush you use every morning (you should use twice a day though) is a product, the desktop or mobile that you are using right now is a product, the app that you are using to read this article is a product too. 

now that you understand what a product is, I should let you know that i am only going to talk about online products (websites or apps) here.
